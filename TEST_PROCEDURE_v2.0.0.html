EN 1. Build & Load

Run ./gradlew build in the project root.
Expected: BUILD SUCCESSFUL, jar produced in build/libs/recraftcollect-2.0.0.jar.
Drop the jar in a server's mods/ folder, start the server.
Expected: no crash, log line Loaded N zombie value entries from config appears.
Inspect config/recraftcollect-milestones.json and config/recraftcollect-zombievalues.json.
Expected: both files exist, populated with the default tier mapping (~70 entries) and 8 default milestones (10k → 1M).

EN 2. Kill Tracking & Tiers

Spawn a vanilla zombie, kill it directly with a sword.
Expected: action-bar shows +1 pts (1) in green, soul particles, score saved (verify with /zk score).
Kill each variant.
Expected: each kill grants 1 point. Cumulative score correct.
If Zombie Extreme is installed, summon a Runner with /summon zombie_extreme:runner and kill it.
Expected: action-bar shows +15 pts in yellow.
If Undead Revamp 2 is installed, summon The Heavy and kill it.
Expected: action-bar shows +1,000 pts in light purple, wither-spawn sound plays.
Run /zk setvalue testmod:* 5, then summon any entity from testmod and kill it.
Expected: 5 points awarded even though that exact entity_id is not in the config.
Set both testmod:* = 5 and testmod:specific_zombie = 100. Kill testmod:specific_zombie.
Expected: 100 points (exact match wins).
Kill a cow, a creeper, a skeleton.
Expected: no action-bar, no score change.

EN 3. Anti-Farm

Tame a wolf, let it kill a zombie without you dealing damage.
Expected: no points awarded to you.
Let a zombie die from environment damage (lava, drowning).
Expected: no points awarded.
Let a golem kill a zombie.
Expected: no points awarded.
Kill a zombie with a bow.
Expected: points awarded (the projectile owner is a ServerPlayer).

Expected: progress and number update immediately.
Expected: hides for the caller, persists across reconnects.

Expected: boss bar disappears outside, reappears inside.

/zk give <you> 10000 to cross the first default milestone.
Expected: chat broadcast "★ [Purger le monde] Les premiers morts-vivants tombent !", levelup sound for all players.
/zk milestone addcmd 10000 give @a minecraft:diamond 1, then re-trigger via /zk milestone resetreached + /zk give <you> 10000.
Expected: every online player receives a diamond.
Expected: ★★★ prefix, UI_TOAST_CHALLENGE_COMPLETE sound, "MONDE PURGE !" message.
Expected: once reached, no rebroadcast on subsequent score changes that cross the same threshold.

EN 8. Persistence

Known Issues / Régressions à surveiller

  • Entity IDs des mods tiers — Les IDs dans recraftcollect-zombievalues.json sont des suppositions basées sur les conventions Forge. Si un kill de zombie modded ne donne pas de points, vérifiez l'ID réel via /data get entity @e[type=...,limit=1] et corrigez avec /zk setvalue <real_id> <points>.
  • Compat sauvegardes v1.x — Les paliers atteints en v1.x (qui correspondaient à des unités de nourriture) restent marqués atteints. Si vous voulez repartir à zéro pour la nouvelle saison Zombie Purge, lancez /zk reset confirm.
  • Wildcards — Un wildcard modid:* est appliqué uniquement si aucun ID exact ne correspond. Si une entrée exacte existe avec valeur 0, elle court-circuite le wildcard.
